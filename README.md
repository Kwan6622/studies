# Studies

## Overview

This repository serves as a collection of my personal learning materials, coding exercises, experiments, and practical implementations across various areas of Computer Science, Data Science, and Artificial Intelligence.

The primary purpose of this repository is to document my self-learning journey, reinforce theoretical knowledge through hands-on practice, and track my technical development over time.

The materials included here are primarily developed through independent study, online tutorials, documentation, and experimentation.

## Topics Covered

The repository covers a range of technical topics, including but not limited to:

- **Python Programming:** Fundamentals, Object-Oriented Programming (OOP), and problem-solving exercises.
- **NumPy:** Numerical computing, array manipulation, and mathematical operations.
- **Pandas:** Data manipulation, cleaning, transformation, and analysis.
- **Data Visualisation:** Creating and interpreting charts using Matplotlib, Seaborn, and other visualisation libraries.
- **Machine Learning:** Fundamental algorithms, model training, evaluation, and experimentation.
- **SQL and Databases:** Querying, managing, and analysing structured data.
- **Other Topics:** Additional technologies, frameworks, and concepts explored throughout my studies.

The repository structure and content will continue to evolve as new topics are explored.

## Repository Structure

Materials are organised into topic-based directories to maintain clarity and accessibility.

Each directory may contain:

- Jupyter notebooks (`.ipynb`)
- Python scripts (`.py`)
- Sample datasets
- Practical exercises and experiments
- Notes and documentation

## Learning Approach

My learning process generally involves:

1. **Understanding:** Studying concepts through online tutorials, documentation, and other educational resources.
2. **Implementation:** Reproducing examples and completing practical exercises to understand their functionality.
3. **Experimentation:** Modifying existing implementations, exploring alternative approaches, and testing different scenarios.
